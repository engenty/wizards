Ein Haken im Plus-Menü: „Extra-Aufwand“. Goose startet ohne, der Editor-Chat mit Haken. Er gilt für das Gespräch. Wenn der Chat Arbeit erkennt, die mehr braucht, erscheint die Karte im Gespräch. Sie blockiert nichts. Unteragenten, die Widgets schreiben, laufen immer mit Extra-Aufwand.

Wo die Modelle herkommen

  • Eine Liste je Anbieter und je Abo-Programm: Name, Stärke (Alltag / Extra-Aufwand), Fähigkeiten, Kontext, „neuestes“.
  • Der Server liefert sie (Manage, mit Zeitstempel). Die Runtime lädt sie beim Start und danach täglich, hält sie im Speicher und auf der Platte.
  • Eine JSON-Datei im Repo ist der Rückfall, wenn der Server nicht antwortet, und bleibt dieselbe Form.
  • „Neuestes Modell“ ist die Voreinstellung. Dann ändert sich nichts bei dir, wenn ein neues Modell kommt, außer dass es genutzt wird.

Cloud gegen lokal

  • Cloud: Standard ist engenty-Guthaben, ohne Modellwahl. „Eigener API-Key“ öffnet die Anbieter-Zeile und die Modellwahl mit „Neuestes Modell“ als Voreinstellung.
  • Lokal: Abo, Key, Gateway, lokales Modell und Guthaben nebeneinander. Das ist die Experten-Ansicht.
